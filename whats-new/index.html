What's New

This page lists every public ClawBox release, newest first. To update your box, open Settings → System Update. For help, see Updating ClawBox.
Some entries are specific to one edition. Where that is the case, the entry says so.
Entries are grouped by release, newest first.

4.3

Screenshots, one shared browser, public app links, xAI Grok, Prime Radiant and updates that ask before they stop your agents.

4.2

Several users on one box, monitor mode, kiosk mode and GitHub backup.

4.1

A fuller chat on phones, reliable conversation restores and auto-merging pull requests.

4.0

The major release that introduced Coding Agent and the new mobile experience.

Earlier releases

Version 3.9 back through the original 2.0 release.
Looking for your installed version? Open Settings → About. To update, open Settings → System Update.

​
ClawBox 4.3

Release status: 4.3.0 is being validated on beta devices before the stable release. A box on main is offered it as v4.3.0 once it is released; see Updating ClawBox.
ClawBox 4.3 adds a Screenshot app and gives you and your assistant one shared browser. An app the Coding Agent built can now be shared through a public link. xAI Grok joins the AI providers, most model changes no longer restart the assistant, you can hold to talk, and the Coding Agent shows its agents at work on a live chart. Prime Radiant, a new app, writes a wiki from your own documents and checks it every night. After updating, the desktop shows a What’s new in 4.3 card. Choose Got it to hide it on all your browsers.

​
Screenshots, built in

The new Screenshot app captures the whole screen, an area or a single window, right away or after a delay. Mark the picture up in its editor, then save it as PNG or JPG to the Screenshots folder, which the Files app shows. Print Screen or Ctrl+Shift+S takes the whole screen and Shift+Print Screen or Alt+Shift+S an area, anywhere on the desktop and with the app closed, and the Screenshot button beside the clock does the same in one click. The keys are left alone while you type in a text field or a Terminal.

​
One browser for you and your assistant

The browser on the box’s desktop and the browser your assistant uses are now the same browser, shown in Agent Browser (the app called Browser before 4.3). Sign in to a site there once and the assistant can use it, and you can watch what it does. The assistant opens its own tabs and leaves yours alone. The browser stays running, so closing it in Agent Browser no longer stops it. If your assistant had signed in to sites in its old hidden browser, sign in to them once in the shared one; Agent Browser’s settings show where the old profile is kept. See The desktop browser for the details and for how to get a separate assistant browser back.

​
Share an app with a public link

Right-click an app the Coding Agent built, on the desktop, and choose Create public link: Temporary, which stops working after the time you choose, or Permanent, which stays on until you disable it. Visitors reach only that app, never your desktop, files or other apps. For an app with its own server, by default they can load its data from its own /api but not change it: The app’s own data in the dialog is Read only unless you choose Read and write, or Off to serve only the app’s pages. Choose Require a password to give the link a password of its own, which you can change or remove later without changing the link. The link’s address changes when the box restarts.

​
xAI Grok, and model changes without a restart

On the OpenClaw edition, Settings and the setup wizard list xAI Grok: paste an API key, or choose Sign in with Grok and approve the sign-in with your SuperGrok or X Premium subscription on any device. Changing the model, installing or switching Local AI, and the local-only switch now take effect without restarting the assistant wherever the change can be applied live, so the chat no longer goes quiet for a minute each time.

​
Hold to talk

Hold the chat’s microphone button while you speak and let go to send; a quick click still starts and stops a recording. Holding F8 while the chat is open does the same, and Esc cancels. Spoken replies download several times smaller, and Auto-play every spoken reply in Settings → Voice plays the reply to a question you typed aloud as well. See Chat.

​
The Coding Agent, on a live chart

The Coding Agent opens on a chart of its agents at work: the planner, each worker, each reviewer and the lead. Choose one to see what it is doing, open its run page, message it or stop it. A message to a working run reaches it right after the step under way. Runs and teams beyond the box’s limit wait in line instead of being refused. When a pull request’s checks fail, the run’s page shows what failed and Fix CI starts a run that fixes it. Each project keeps run notes of what earlier runs learned, which you can view and edit on the project page. Runs use fewer tokens by default. Under Advanced, the Coding Agent’s settings have a new Token use group: Run instructions (Short instructions by default), Helper agents (Only when it pays off) and Browser and media tools (Only for visual work). Unless you changed them, a new run takes at most 200 steps instead of 400 and gets one attempt at what it had to deliver instead of three. A box with no effort saved starts runs at Very high instead of Ultracode; a box whose Coding Agent setup was finished before 4.3 keeps the Ultracode that setup saved until you change it. A run whose task and folder do not look visual no longer gets the browser, picture or speech tools; set Browser and media tools to Always to give them to every run.

​
Prime Radiant, a living wiki

Prime Radiant is a new app, on both editions, that keeps a wiki for you. Point it at your documents and it writes a page for each one, listing the facts it found with where each came from and how sure it is. Every night it tidies the wiki, looks for facts that contradict each other, and asks you in Review about anything it cannot settle alone; a page you verified is never rewritten without asking you first. History shows every change and Undo reverses one. Open it from its icon on the desktop, next to Memory Shard. Adding documents needs the box signed in to ClawBox AI. See Prime Radiant.

​
Updates that ask before they stop your agents

An update stops the assistant and restarts the box’s web server, which used to cut off any agent work in progress. Now, when coding runs or assistant tasks are working, Update first says Agents are working right now — how many runs are active, and that the update stops them mid-task — with Cancel to wait and Update anyway to go ahead. The System Update screen was redesigned around the steps it runs, with what is new in the version being installed beside them; on a beta box it names the build it installs. The box reboots only when the update brings something that needs a boot, and otherwise just restarts its services. An update that fails puts the box’s code back to match the build it is still running, one that was cut short resumes from the step it was on, and an OpenClaw update that is already at the pinned version skips the reinstall and keeps the assistant running. The assistant can no longer start a system or OpenClaw update by itself: when it asks, you confirm. See Updating ClawBox.

​
Sign out of a provider, and protect ClawBox’s own files

Every connected AI provider in Settings → Providers now has Sign out of <provider>, on OpenClaw and Hermes alike, and you can sign the box out of ClawBox AI there too. Protect ClawBox files from the agent, a new switch in Settings → Harness that is on by default, stops the assistant’s own file and shell tools from deleting or overwriting ClawBox’s own files and the local AI models.

​
Switching between Anthropic accounts, fixed

  • An account is no longer marked expired because the box could not reach Anthropic to renew its sign-in, for example after the box was off. The box tries again on the next request; only Anthropic itself refusing the sign-in takes an account out.
  • An account whose organization has switched off Claude subscription access for Claude Code is marked Needs re-authentication straight away, and the chat and coding runs move to the next account.
  • The account the box switches to is used right away, and a failure is counted only against the account the assistant was really running on, so a switch is not undone by a failure that came from the account before it.
  • Claude’s new per-model weekly limits are read too: a model whose week is spent moves only the runs on that model to the next account.
  • On OpenClaw, a chat whose account reached its usage limit moves to another account on its next message instead of answering with the limit message.
See Multiple Anthropic Accounts.

​
Smaller things

  • Settings → Appearance → Remote desktop resolution sets the remote desktop to 1280 × 720, 1600 × 900 or 1920 × 1080. Changing it restarts the remote desktop briefly.
  • When the cloud voice does not answer, a spoken reply gives up after about 20 seconds and a line under the reply says so, instead of a silent minute.
  • A coding run started from another browser or device shows its card in the open chat within about half a minute, without a reload.
  • The Store app has a ClawBox Apps category: Install puts a published app in the Coding Agent’s project folder and on the desktop. A Coding Agent project with a clawbox.json gets Publish to ClawBox Store, which says it is coming soon until publishing is open to your account.
  • In the Terminal, Ctrl+V pastes a picture into Claude Code as an attachment.
  • On a laptop, the tray shows the battery level beside the clock.
  • On the ClawBox desktop session, a Google Chrome icon opens your own Chrome as a window on the box’s screen.
  • Pressing Stop in the chat leaves a grey “Stopped.” line under the reply.
  • On Hermes, documents attached in the chat reach the assistant.
  • When ClawKeep refuses a backup, it says why, with the sizes involved.
  • On your own x64 machine, a Cloudflare Tunnel download that stalls no longer holds up the install.
  • OpenClaw is updated to 2026.10.9 and Hermes Agent to v0.22.5.
  • Coding runs can also run on OpenAI, through the Codex CLI: connect an API key or a ChatGPT sign-in in the Coding Agent’s settings. A run can tell the assistant that started it about a question or a blocker while it works, and the chat that started a run hears when it ends.
  • Long Settings tasks — installs, model downloads, provider sign-ins, channel setup — run in the background with a card in the desktop’s corner and survive closing Settings; a waiting task or a download can be cancelled. A Local AI install that cannot run beside another one waits in line instead of being refused.
  • On the on-device model, a conversation that grows too long offers a new chat instead of a minutes-long shortening. On OpenClaw with ClawBox AI, a long chat is shortened automatically.
  • On OpenClaw, memory search reads the assistant’s memory and no longer indexes every past chat, which kept its databases growing; the index is rebuilt once after the update. Settings → System → Device → Agent databases can compact those databases, off until you turn it on.
  • Users moved into Settings → System → Users, and the owner can share the OpenClaw app with all users from there (off by default).
  • On Hermes, the chat resumes the same conversation after a reload, a restart or an update, documents you attach reach the assistant, and the chat shows the Hermes icon.
  • The ClawBox AI usage card calls the five-hour allowance Short-term limit (5 hours), and a message that failed on a spent allowance says which one and when it frees up.
  • The Telegram card no longer says the channel is active while the bot is not receiving messages.
  • When one of the assistant’s scheduled jobs fails, keeps being skipped or does not run when it is due, the desktop tells you, and Telegram too when a bot is connected. Settings → Harness → Scheduled job alerts lists the jobs in trouble.
  • Factory reset now also empties Projects, Music, Pictures, Videos, Public and Templates and removes loose files in the home folder, keeping the folders themselves.
  • Only the owner can finish first setup, and the password step says as you type when a password is too short or the two entries do not match.
  • A box that cannot read its own settings for a moment shows its plan as unknown, not Free.
  • The Projects app has been removed, together with its pinned folders and the GitHub backup in Files. Your folders stay where they are and still open in Files; copies already on GitHub stay there, and their daily backup stops.

​
Before you update to 4.3

  • Update from 4.2.x, 4.1.x or 4.0.x in Settings → System Update. On the OpenClaw edition sudo bash install.sh over SSH works too; on the Hermes edition System Update is the only route.
  • The move to 4.3 is one-way on OpenClaw. The update moves OpenClaw’s data to the newer format OpenClaw 2026.10.6 and later use, so the box cannot go back to an earlier release afterwards. An update that lacks the disk space for the move stops before it changes OpenClaw and says how much it needs.
  • The update moves the box to Node.js 24.22.1 or newer, the October 2026 Node.js security release, on every edition.
  • Sites the assistant was signed in to in its old, separate browser need one sign-in in Agent Browser.
  • Your data is preserved, and the edition lock is untouched.

​
What works differently

  • The assistant uses the browser on the box’s desktop rather than a hidden one of its own. See The desktop browser for giving it a separate browser again.
  • The Coding Agent no longer merges a finished run’s work into the project folder by hand; the work stays on the run’s branch.
  • A coding run whose task and folder do not look visual no longer gets the browser, picture or speech tools, even with Let runs draw pictures or Let runs record speech on. Set Browser and media tools to Always to give them to every run.

ClawBox 4.2

Released October 5, 2026 ClawBox 4.2 lets several people share one box, each with a user of their own. It spreads the desktop over several monitors, adds a drop-down terminal and a proper kiosk mode. Project folders can be backed up to GitHub in one click, ClawKeep backups are fixed, and testing on real ClawBox hardware fixed the problems it found. After updating, the desktop shows a What’s new in 4.2 card. Choose Got it to hide it on all your browsers.

​
Several people, one ClawBox

The owner adds users in Settings → Users. Each person signs in with their own name and password, and gets a desktop and a Terminal of their own; their Terminal runs as their own account on the box. Settings, installed apps and the assistant stay with the owner. The sign-in page only asks which user you are on a box that has more than one, and removing a user signs them out everywhere.

​
Monitor mode, with a drop-down terminal

With the ClawBox desktop session, one desktop spans a row of monitors. Arrange them in Settings → Monitors: drag them into place, choose the main one, and set resolution, refresh rate, scale, rotation and mirroring, plus brightness where the monitor allows it. A new layout is undone after 20 seconds unless you keep it. Press Win+Down and a terminal drops down from the top of the screen; press it again to hide it.

​
Back up project folders to GitHub

In Files → Projects, Back up copies a folder to a private GitHub repository, using the Coding Agent’s GitHub sign-in. After the first backup you can back up again, see the history, open the copy on GitHub, or turn on a daily backup that runs only when something changed. Files that look like passwords or keys, files over 50 MB and nested repositories are left out, and you are told which. A folder that already has its own GitHub remote is pushed to its current branch and never force-pushed.

​
Kiosk mode

When ClawBox shows its desktop full screen, every page the desktop opens gets a ClawBox bar with tabs, back, forward, reload and an address field, and a new tab opens a ClawBox start page with search. The desktop’s shelf gathers those pages under one Web icon, so the desktop is always one click away.
Monitor mode, the drop-down terminal and kiosk mode need the ClawBox desktop session. The update does not switch them on, and a ClawBox without it looks and works as before.

​
Choose OpenClaw or Hermes at setup

During first setup, right after Wi-Fi, a new ClawBox asks which assistant it should run: OpenClaw, which we recommend for most people, or Hermes. When your order named one, it is already selected. The box sets up your choice and removes the other to free space, which takes a few minutes. A box that already runs an assistant is never asked. See Editions.

​
ClawKeep backups fixed

  • Snapshots no longer carry old backup archives along, which had made them grow until the account was full.
  • A link that cannot be archived is skipped and named, instead of failing the backup.
  • Auto-backup switched off while the ClawKeep account is full is only paused: the ClawKeep card says so, and it switches back on by itself once backups can run again.

​
Fixes from hardware testing

  • Voice input works with ClawBox AI’s transcription again, and falls back to the box’s own Whisper when the cloud cannot answer. Installing speech recognition from Settings → Local AI works on a freshly set-up box.
  • Spoken replies no longer fail when the voice engine has to start from cold.
  • Retry on the ClawBox AI plugin installs it and switches it back on, and the plugin no longer loops through a repair on every start.
  • A box left on an older build by a failed update repairs itself at the next boot.

​
Smaller things

  • Desktop windows and running Terminals survive a page refresh.
  • Your chat tabs are the same on every device, and files the assistant sends in the web chat now download.
  • The Files app selects several files at once, moves them by drag and drop, and lets you choose where an upload goes.
  • With several Anthropic accounts, the chat and every coding run switch to the next account together when one reaches its limit.
  • The update screen shows what is new in the version being installed.

ClawBox 4.1

Released September 25, 2026 ClawBox 4.1 makes chat easier on phones, makes conversation recovery more reliable, restores saved data for older web apps, and improves automatic coding-agent pull requests. After updating, the desktop shows a What’s new in 4.1 card. Choose Got it to hide it on all your browsers.

​
More of the phone for the chat

On a phone the chat opens full screen. Its header and the message box’s options fold away, so the conversation gets the screen, and the text size can be set from 85% to 150%. Both choices are remembered in that phone’s browser. The desktop chat is unchanged. See Chat.

​
A conversation that cannot reopen says why

Reopening a conversation used to wait with nothing to press when the box did not answer. Now every step of it has a deadline. When the box cannot bring the conversation back, the chat says why (the conversation is busy, the box did not answer, or it could not be restored) and offers Try again. The chat panel also offers Start a new chat, which opens a fresh tab and deletes nothing.

​
Web apps built before 4.0 find their data

ClawBox 4.0 gave every web app its own private storage area. Some apps made on 3.9 could therefore no longer see data they had saved before the update. Version 4.1 safely copies that data into the app’s new storage the first time it starts. The original data remains in place, so it is still available if you roll back.

​
Coding agent pull requests merge when green

Turn on Merge a pull request after review rounds clear and the coding agent can ask GitHub to merge its pull request after every required check passes. It will wait if a check fails, a conflict exists, or a reviewer still has an unanswered request. Pull requests marked hold or do-not-merge, and pull requests into main, are never merged automatically. Runs using your own Anthropic account now default to Claude Opus 5.5.

​
More reliable updates and backups

  • Updates now stop safely before making changes if the box contains data created by a newer OpenClaw version.
  • Codex and ClawBox AI plugins left in Needs repair are retried automatically. The Providers screen shows Repairing… while this happens.
  • An active swap file no longer causes an update to fail.
  • ClawKeep handles common backup interruptions more gracefully and still stops safely when it finds damage that could risk your backup.
  • Index now can rebuild a Memory Shard index left unusable by a 4.0 update.

​
Smaller things

  • The chat’s default Anthropic model is Claude Opus 5.5 when you have not picked one.
  • On a phone, View on a coding-run card brings the run’s page up in front of the chat.
  • A coding-run card leaves the chat five seconds after its run finishes cleanly; the 🤖 chip brings it back.
  • Settings → About, System Update and the What’s new card all name the same version, 4.1.0.

​
ClawBox 4.0

Released September 21, 2026 The fourth release turns the box from an assistant you talk to into one that also does the work: it writes code in your repositories and opens pull requests, it keeps one address you can reach from anywhere, it backs itself up, and it fits on a phone screen.

​
A coding agent that does the whole job

Coding Agent on the desktop hands a whole task to Claude Code running on this box. Point it at a folder, describe the job, and it reads and writes files there, runs commands, and reports what it did. Each attempt is a run, kept with its own page: the task, the folder, who asked for it, how long it took, how many steps it took, the files it touched, the models it used, and the final summary. The runs list keeps the recent runs in front of you and refreshes itself every few seconds while one is live. The box keeps the last 30 runs: a run that is live, paused or drafted is never dropped, and once there are more than 30 the oldest finished one falls off the end.

​
Runs open pull requests, and review their own work

With the auto-PR switch on, a run that changes files in a git repository pushes its own branch and opens a pull request for it. The run’s page carries the pull request number, its title and its state, so you do not have to go looking on GitHub. With the review switch on, a completed run is followed by an automatic review pass: a second run that reads the first one’s work and reports what is wrong with it. The review is a run of its own, linked to the one it reviewed. When a pull request comes back with comments, or its checks fail, the agent can work the feedback in rounds until the thread is clear.

​
More than one Anthropic account for coding runs

Settings → Providers → Anthropic accounts now holds several Claude Pro/Max accounts and API keys, in the order you choose. When the account a coding run is using hits its usage limit, the run moves to the next account and continues in the same session. Your first account takes over again as soon as its limit resets. If every account is limited, the run waits and resumes by itself at the first reset. Every move is recorded on the run’s page, so you can see which account paid for which part of the work. See Multiple Anthropic Accounts.

​
Watch a long task from the chat

A task that takes a while now shows a progress card in the chat, pinned between the conversation and the message box. It names the step the assistant is on, counts the steps that are done against the total, says when it last moved, and carries the assistant’s own note about what it is doing. Fold it away and it stays folded, on every chat surface, until you open it again.

​
A terminal on the box

Terminal is a real terminal, not a log viewer. It connects to a shell on the box, so you can type commands, run a build, and watch it work. It has tabs, copy and paste, a right-click menu, and settings for the font and the colours. Where the browser offers WebGL it draws through the GPU, so the text stays sharp on a high-density screen, and where it does not the terminal falls back to drawing in the page.

​
Steer a run while it is running

The assistant can now drive the coding agent through its own tools: start a run, read its state, resume it, list the projects it knows about, and send a message into a run that is already going. So you can change your mind mid-task from the chat, or from Telegram, without stopping the run and starting again. The same tool set reads Memory Shard, Local AI and your ClawBox AI usage.

​
Your box keeps one address

A box linked to your portal account gets a permanent address of its own, of the form <your-box>.clawbox.tech, and runs a named Cloudflare tunnel to serve it. The address does not change when the box reboots, when the tunnel restarts, or when your home IP moves, so a bookmark keeps working and the address is worth writing down. The old quick tunnel is still there as the fallback, with its long random trycloudflare.com address, for a box that has no named tunnel yet. Both live in Settings → Remote Control. See Networking.

​
Switch your box between OpenClaw and Hermes

A box that shipped as one edition can now be re-made as the other from Settings → Harness, without a reflash and without a second box. The button installs the other agent, re-bakes the edition lock, carries your ClawBox AI sign-in, your Telegram bot and your memory folders across, and reloads the desktop. The same button swaps back. It needs the Max plan, an internet connection and about 3 GB of free disk. Staying on the harness your box already runs costs nothing. See Switching editions.

​
ClawBox AI runs on DeepSeek V4

ClawBox AI runs DeepSeek V4 Flash on every plan. Free/Pro Tier is the default; Max Tier is the same DeepSeek V4 Flash with the Max plan’s limits and needs the Max plan. Both take a one-million-token context window and both are text in, text out. You do not have to choose a model on ClawBox AI: the chat names the provider and the plan decides the rest. See ClawBox AI.

​
ClawKeep backs the box up

ClawKeep on the desktop takes your agent’s state, its configuration, its credentials and its saved conversations, and keeps them off the box. Pair it once with your account and it can back up on a schedule or when you press the button, hold several snapshots, and restore any of them onto this box or a replacement. The archive can be encrypted with a passphrase only you hold. Its card says when the last backup ran, how much cloud space you are using, and how many snapshots you have.

​
The chat opens first on a phone

On a phone the box opens the chat, not the desktop: below 768 pixels wide, the chat is the landing surface, with a thumb-sized microphone, a composer that fits a portrait screen, and a Back button that walks up one level at a time instead of dumping you at the start. An installed home-screen app with a touch pointer gets the same treatment.

​
Gemma 4 E2B runs on the box

The on-device agent model is Gemma 4 E2B Q4/INT4, Google’s own quantisation-aware release, running under llama.cpp. It is a 3.1 GB download and holds about 3.3 GB of memory on an 8 GB Jetson, which leaves room for the rest of the box to work. Install it from Settings → Local AI. See Local AI.

​
Change model without restarting anything

Provider, model and reasoning effort are three pills beneath the chat panel’s message box. Picking a different one applies to the running agent: nothing is restarted and there is no 30-second reconnect between you and the next message. See Chat.

​
A failed message tells you what the provider said

When a turn fails, the chat now prints the provider’s own reason instead of a generic “the run failed”. When a fallback model answered in place of your first choice, the reply says which model wrote it.

​
Slash commands with autocomplete

Type / in the chat composer and the commands your agent actually publishes appear in a menu, each with its own description and argument hint. The list comes from the agent itself, so it includes the commands your skills and plugins added. Both editions.

​
The assistant can ask you a question

When the agent needs a decision, it shows a card with the options it is choosing between, each with the consequence spelled out, plus a box for an answer of your own. Nothing happens until you send one.

​
Spoken replies

The chat can read a reply out loud, with a player on the bubble and a scrubber. It is off by default: turn it on in Settings → Voice → Spoken replies. A box on the Max plan speaks with the ClawBox AI cloud voice; any box can install a voice of its own.

​
ClawBox AI: usage, credits and plans in one card

Settings → Providers now shows your weekly chat allowance, the 5-hour burst window, the images, speech and memory-indexing meters, and your credit balance, read from your account rather than guessed on the device. See ClawBox AI.

​
Voice, transcription and memory indexing use your plan’s cloud

On a box connected to ClawBox AI, on every edition, speech-to-text, text-to-speech and the memory index default to the cloud your plan covers instead of running engines on the box. The engines on the box stay the fallback, and stay selectable. A choice you make yourself is never overwritten. See ClawBox AI → What your plan powers.

​
Nothing heavy is installed behind your back

A fresh install and every update now install only the local AI runtime and the small on-device model. The voice engine, the transcription engine and the 640 MB embedding model are installed when you ask for them, from Settings → Local AI or from Memory Shard’s own setup. Updates got much shorter as a result. See Local AI.

​
Local AI is one inventory

Settings → Local AI lists every model that can run on the box, the agent model, the voice, speech-to-text and memory search, with Install, Uninstall, Enable and Disable on each row and what each one is doing right now. On the OpenClaw and dual editions, once the box’s own model is primary or fallback, a Local-only mode switch appears there and routes everything to the box, switching every cloud provider off. The Hermes edition has no equivalent.

​
A Hermes plugin you install now reaches the chat

Hermes looks for plugins once, when the assistant starts, so a plugin installed or enabled after that was invisible to every chat, new conversations included, however healthy it looked from the command line. The box now handles it: when your plugins change, the assistant restarts itself so it picks them up, and the desktop shows a notice naming the plugin and telling you to open a new chat. The assistant can ask for the same restart itself, right after it installs something for you. The restart closes the chat window you have open. That is what the notice is for: open a new chat and the plugin is there. Hermes edition. See Hermes Edition.

​
Memory Shard on both editions, and the cloud index by default

Memory Shard turns your notes, your past conversations and folders of your own documents into an index the assistant can search. It works on the Hermes edition too, and its settings let you choose where the index is embedded: the ClawBox AI cloud, or the model on the box. Since this release the cloud is the default on every edition wherever your plan covers it. A Pro or Max box that is connected indexes there without choosing anything, so there is no 640 MB model to download before your first index. On this box is the opt-in and is never overridden once you pick it, and a box that could not reach the cloud moves there by itself, with the rebuild that move needs, once a plan that covers it is linked. Memory Shard needs a Pro or Max plan. See Memory Shard.

​
Discord: paste the token, and that is all

Settings → Channels → Discord now reads your application id and your servers from Discord itself, builds the invite link on the box, and gives the server owner access as soon as the bot joins. There is no Application ID field to fill in any more, and no need to tell the assistant your user id. See Messaging channels.

​
Sign in with a subscription you already pay for

Besides API keys, the provider step takes Claude Pro/Max, ChatGPT Plus/Pro and Google One AI Premium sign-ins. On the Hermes edition, Anthropic and GitHub Copilot sign in from the panel again, with the link and the code shown on screen.

​
Pick your desktop companion

Settings → Appearance → Mascot Pet offers the ClawBox crab, which ships with the box and works offline, plus a gallery of community pets that download when you pick one. Every edition. See Desktop & appearance.

​
Installing on your own x64 machine

install-x64.sh checks the host before it changes anything: ports already in use, services it would replace, desktop services it would take over, and it lets you choose the web, gateway and terminal ports. It can leave existing desktop services alone.

​
Smaller things

  • ClawBox AI chat has no model to choose, so it names the provider and shows no model pill beside it. Its reasoning control starts at Medium.
  • A sign-in that restarts the agent now re-points the chats you already have open, so an open conversation cannot keep running on the old model while the pills name the new one.
  • The assistant’s own tools grew: it can read and send email you have approved, generate pictures and audio, drive the coding agent, and search Memory Shard on the Hermes edition. See Agent Interface.
  • A box reached on a name that is not its own is refused on port 80, which closes a DNS-rebinding gap.
  • An update that dies half way through now resumes instead of leaving the box in a state nobody can describe.
