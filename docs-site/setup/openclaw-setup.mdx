ClawBox ships with OpenClaw pre-installed, so most of this is already done for you.
This guide is the full reference for configuring channels, voice, models, and advanced
options — whether you're on a ClawBox or a DIY install.

## Prerequisites

- **Node.js 24.22.1 or newer in the 24 line, or 26.12.1+** installed — the October 2026 Node.js security releases the pinned OpenClaw requires (pre-installed on ClawBox, and a ClawBox update moves an older Node up by itself; the core refuses 25)
- **4 GB+ RAM** recommended
- Linux, macOS, or Windows
- Always-on internet connection

## Telegram

<Note>
For ClawBox's guided setup, use **Settings → Channels → Telegram** and see
[Messaging Channels](/guides/messaging-channels). Use the manual steps below for
self-hosted OpenClaw setups or fallback configuration.
</Note>

<Steps>
  <Step title="Create a bot">
    Open Telegram and search **@BotFather**.
  </Step>
  <Step title="Name it">
    Send `/newbot` and follow the prompts to create your bot.
  </Step>
  <Step title="Copy the token">
    BotFather gives you an **API token** — copy it.
  </Step>
  <Step title="Add it to OpenClaw">
    Paste the token into your OpenClaw config (Channels → Telegram).
  </Step>
</Steps>

## Discord

<Note>
On a ClawBox, **Settings → Channels → Discord** does all of this for you: paste the bot
token and the box sets the channel up. Use the manual steps below only on a self-hosted
OpenClaw install.
</Note>

<Steps>
  <Step title="Create an application">
    Go to the **Discord Developer Portal** and create a new application.
  </Step>
  <Step title="Create a bot">
    Add a bot to the application and copy its **token**.
  </Step>
  <Step title="Enable intents">
    Turn on the required gateway intents for the bot.
  </Step>
  <Step title="Add it to OpenClaw">
    Paste the token into your OpenClaw config (Channels → Discord).
  </Step>
</Steps>

## Voice pipeline

On a ClawBox, voice is set up from the desktop:

- **Settings → Local AI** installs **Whisper** (speech to text on the box) and the **Kokoro**
  voice (spoken replies on the box). With ClawBox AI, speech to text runs in the cloud on every
  plan and spoken replies on Max — see [ClawBox AI](/guides/clawbox-ai#what-your-plan-powers).
- **Settings → Voice** chooses how replies are spoken: **Auto-play every spoken reply** and
  **Short spoken answers** are there, both off by default.
- In the chat, hold the microphone button (or **F8**) to talk — see [Chat](/guides/chat).

## AI models

- Add your **API key** (Anthropic, OpenAI, Google, OpenRouter, xAI), sign in with a subscription you already pay for, **or** use the model on the box
- Configure model preferences
- Test with a simple prompt

See [Choose Your AI Provider](/setup/choose-ai-provider) for the full provider list.

## Advanced configuration

- Set up **systemd** for auto-start (pre-configured on ClawBox)
- Configure **browser automation**
- Set up **cron jobs** for monitoring and scheduled tasks

## Pro tips

<Tip>
- Run `openclaw status` to check that all services are running.
- If something misbehaves after a config change, restart the gateway — **on a ClawBox** the service is `sudo systemctl restart clawbox-gateway` (there is no `openclaw` unit); on a DIY install use whatever unit name you created.
- Tail logs in real time — ClawBox: `journalctl -u clawbox-gateway -f`; DIY: `journalctl -u <your-unit> -f`.
- Keep the software current for the latest features and security patches — see [Updating ClawBox](/support/updating).
</Tip>
