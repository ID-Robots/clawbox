ClawBox is flexible about which AI model powers your assistant. You pick during setup
and can change it later.

## ClawBox AI (default)

Works immediately, no keys to manage. The simplest way to get started — and a great
default for most people.

## Bring your own provider

Prefer a specific model? ClawBox treats these as first-class options:

paste your API key. ClawBox stores it on the device.

## Local models

For fully on-device inference, ClawBox supports local **Ollama** and **llama.cpp**
models. This is an option for users who want it rather than the default path.

<Note>
Local model performance depends on your hardware. **ClawBox Workstation** (DGX Spark,
128 GB unified memory) can run models up to ~200B parameters locally; **ClawBox
Connect** (Jetson Orin Nano) is best paired with cloud providers or smaller local models.
See [Hardware](/hardware/clawbox-connect).
</Note>

## Reasoning effort

You can control how hard the model thinks before answering, per conversation, from the brain icon in the chat header (or with `/think <level>`). More thinking gives better results on hard problems and costs more time and tokens.

The available levels depend on the model you are using. With **ClawBox AI**, three are available: **Off** (the fast default), **High**, and **X-High** (maximum reasoning). Off keeps everyday replies quick; you opt in to reasoning when a task needs it.

Other models offer their own sets — some more, some fewer — and models with no reasoning control at all, such as the on-device local model, hide the control completely. The chat header always shows only what the selected model actually supports.

<Note>
For the technical detail of how these levels are configured — and why they are set in code rather than by hand — see [AI Providers → Reasoning effort](/technical/ai-providers#reasoning-effort).
</Note>

## Switching later

You can change provider any time from the device settings — no re-setup required.
