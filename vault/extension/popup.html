Pair this browser

The browser on a ClawBox pairs by itself once the vault has a PIN: open ClawBox Vault on the desktop and choose one. To pair with a code instead:

  1. Open ClawBox Vault on the ClawBox desktop and unlock it.
  2. Go to Browser, open Pair with a code instead and click Show pairing code.
  3. Type the 6-digit code here.

Vault locked

Fills, copies and agent fills are paused for this browser. Enter the vault PIN to unlock.
