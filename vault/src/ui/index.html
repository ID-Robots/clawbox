      Browser

      The ClawBox Vault extension fills and saves logins in the browser on this ClawBox, the one the assistant uses.

      This box's browser

      How it gets there

      1. The extension is already installed in this ClawBox's browser. There is nothing to download.
      2. It pairs by itself, within a minute of the browser starting, once the vault has a PIN.
      3. Open the browser from the desktop if it shows as not connected.

      Unpair stops fills and saves until you pair the browser again here.

      Pair with a code instead

      For a browser on this ClawBox that did not pair by itself: click the ClawBox Vault icon in its toolbar and type the code. A code works once, for 5 minutes, and replaces the browser paired before.

      Assistant

      The assistant on this ClawBox can list, match, save and fill logins. No tool ever gives it a password.

      Built in

      The vault tools are part of the assistant. There is nothing to configure: they work once the vault has a PIN and the browser is paired.

      Tools: vault_list, vault_match, vault_fill, vault_save, vault_generate, vault_delete, vault_audit, vault_cards_list, vault_card_fill.

      Every call is written to Activity with the entry and the site, never with a secret.

      How a fill works

      1. The assistant opens the login page in the browser and calls vault_fill(url).
      2. The vault queues a fill for the paired extension.
      3. The extension finds the matching tab, fetches the login for that one fill and types it into the real inputs.
      4. The assistant gets back only a status: filled, no_form, no_tab or origin_mismatch.

      Cards: vault_card_fill opens a confirmation window in the browser (site, card label, last 4). It fills only after you click Confirm; the assistant gets declined or timeout otherwise, and never the number.

      Activity

      Every save, delete, reveal, fill and pairing. No secrets are written here.
